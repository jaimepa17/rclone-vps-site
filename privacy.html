Política de Privacidad

rclone-vps · Última actualización: 7 de noviembre de 2026

Esta Política de Privacidad describe cómo la aplicación rclone-vps (“la Aplicación”) accede y utiliza los datos de Google.

1. Uso personal

La Aplicación es de uso exclusivamente personal de su propietario. No está destinada al público, no permite el registro de terceros y no se ofrece como servicio comercial.

2. Qué datos se acceden

Con la autorización del propietario, la Aplicación accede únicamente a los archivos de su propia cuenta de Google Drive para subirlos, descargarlos y mantenerlos sincronizados. No accede a datos de otras cuentas.

3. Cómo se usan los datos

Los datos se usan exclusivamente para las funciones de copia y descarga solicitadas por el propietario. No se usan para publicidad, perfilado ni fines distintos a la sincronización.

4. Almacenamiento y compartición

La Aplicación no recopila, almacena, vende, alquila ni comparte datos personales con terceros. Los archivos permanecen en la cuenta de Google Drive del propietario y en su servidor privado. Las credenciales de acceso se guardan localmente en el servidor del propietario y no se transmiten a terceros.

5. Servicios de terceros

La Aplicación utiliza la API de Google Drive. El uso de los datos obtenidos a través de las API de Google cumple con la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

6. Conservación y eliminación

El propietario puede revocar el acceso de la Aplicación en cualquier momento desde la configuración de seguridad de su cuenta de Google. Al revocarlo, la Aplicación deja de tener acceso a los datos.
