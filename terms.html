Condiciones del Servicio

rclone-vps · Última actualización: 7 de noviembre de 2026

1. Uso personal

rclone-vps es una aplicación de uso exclusivamente personal de su propietario. No se ofrece como servicio al público, no permite el registro de terceros y no tiene fines comerciales.

2. Función

La aplicación sincroniza archivos entre un servidor privado y la cuenta de Google Drive del propietario, usando la API de Google Drive con su autorización.

3. Responsabilidad

La aplicación se proporciona “tal cual”, sin garantías de ningún tipo. El propietario es el único responsable del uso que haga de ella y de los archivos que decida copiar o descargar.

4. Servicios de Google

El uso de la API de Google Drive está sujeto a las Condiciones del Servicio de las API de Google y a la Política de Datos de Usuario de los Servicios de API de Google.
